# Hohmann-Transfer-Orbit-Simulation-using-STK
Hohmann Transfer Orbit Simulation using STK – Orbital mechanics analysis including ΔV calculation and transfer ellipse visualization

 Hohmann Transfer Maneuver Simulation (STK)

This project demonstrates a classical Hohmann Transfer Orbit simulated using Systems Tool Kit (STK).

 Project Overview

The simulation models an orbital transfer between two circular Earth orbits using a two-impulse maneuver:

- Initial circular orbit
- Transfer ellipse
- First burn (ΔV1)
- Second burn (ΔV2)
- Final circular orbit

The project focuses on understanding orbital energy change, velocity requirements, and mission planning fundamentals.

---

 Tools Used

- Systems Tool Kit (STK)

---

 Orbital Mechanics Background

The Hohmann Transfer is the most fuel-efficient two-impulse maneuver used to transfer between two coplanar circular orbits.

Key parameters analyzed:

- Semi-major axis of transfer ellipse
- ΔV at perigee
- ΔV at apogee
- Time of flight
